# Simulation de monitorage hospitalier

Projet académique de simulation d'un système de monitorage hospitalier multiparamétrique.

## État du projet

**Phase actuelle : analyse documentaire et fonctionnelle.** Aucun code applicatif n'a encore été développé.

Le périmètre confirmé est le monitorage hospitalier : environnements de soins, moniteurs de chevet, télémétrie hospitalière, centrales de surveillance, alarmes, processus métiers et intégration informatique.

## Documentation

Le dossier de référence est [`docs/analyse/monitorage-hospitalier/`](docs/analyse/monitorage-hospitalier/README.md).

Il est découpé par thèmes :
- environnements de soins ;
- systèmes et équipements ;
- métiers et processus ;
- besoins et scénarios ;
- sources.

Les documents de cadrage initiaux sont conservés dans [`docs/analyse/`](docs/analyse/README.md).

## Principes

- Distinguer faits sourcés, fonctionnalités annoncées par les fabricants et besoins déduits.
- Citer les sources pour chaque cas étudié.
- Ne pas inventer de seuils ou protocoles médicaux.
- Utiliser des données synthétiques dans les simulations.
- Garder une trace des décisions, questions ouvertes et prompts de recherche.
