## 5. Précautions d'interprétation

- Les spécifications fabricants sont des sources primaires pour comprendre leurs produits, mais restent des documents commerciaux ou de documentation produit.
- La présence d'une fonction dans une brochure ne prouve pas qu'elle est activée ou utilisée dans tous les déploiements.
- Les études étrangères aident à identifier des problématiques métiers, mais leur organisation n'est pas automatiquement transposable en France.
- Les textes réglementaires et référentiels français doivent primer pour décrire le cadre national.
- Les sources peuvent être mises à jour ; avant une décision technique, vérifier la version et la date de consultation.
