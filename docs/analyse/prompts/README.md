## Règles d'utilisation

- Remplacer la date de référence par la date réelle de la recherche.
- Rechercher les informations actuelles lorsqu'elles peuvent avoir évolué.
- Privilégier les textes officiels, les documentations des projets et les retours d'expérience clairement identifiés.
- Associer chaque affirmation importante à une source.
- Conserver les URL, dates de consultation, versions et limites.
- Ne jamais inventer de métriques de marché, d'indications cliniques, de certifications ou de déploiements.
- Distinguer les informations des fournisseurs des évaluations indépendantes.
- Ne pas utiliser de données personnelles ou médicales réelles dans les exemples.

## Journal des recherches

Chaque nouvelle recherche importante devra ajouter une entrée indiquant :
- le prompt utilisé et sa version ;
- la date et le périmètre de recherche ;
- les requêtes ou mots-clés importants ;
- les sources retenues et écartées ;
- les faits nouveaux ;
- les questions restant ouvertes ;
- les documents modifiés.
