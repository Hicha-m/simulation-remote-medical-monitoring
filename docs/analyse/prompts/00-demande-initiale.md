## Sujet du projet

**Simulation d'un système de télésurveillance médicale**

Mots-clés : Java, réseau, sécurité, interface graphique, base de données.

L'objectif du projet est de concevoir et de développer une application simulant un système de surveillance médicale. Plusieurs données sur les patients (fréquence cardiaque, tension artérielle, saturation en oxygène, ...) arrivent régulièrement au niveau d'un serveur qui les traite et les stocke dans une base de données. Les différents appareils envoyant les données seront simulés par des programmes clients. Un tableau de bord permettra au personnel hospitalier de surveiller les patients à distance et en direct (les données reçues doivent être affichées le plus rapidement possible). Les données étant sensibles, l'aspect sécurité de ce projet est important.
